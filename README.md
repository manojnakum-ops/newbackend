# newbackend

## Run locally

Install dependencies with npm ci, configure config.env, and run npm start.

Local environment files are excluded from Git. AWS integrations require AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY; OpenAI requires OPENAI_API_KEY.

OAuth integrations require FACEBOOK_CLIENT_SECRET and GOOGLE_CLIENT_SECRET.

Uploaded user files, generated reports, sample database records, and legacy deployment workflows are excluded.
